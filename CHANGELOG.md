# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/).

## [Unreleased]

### Added (November 2026)
- **Live mode:** real ECMWF ensemble rain (low / likely / high) and a forecast alert line; ground wetness and tide from Open-Meteo.
- **Score follows the water:** after the flood run the index switches to the simulated water (final stage).
- **Replay and validation:** past days with the forecast or the rain that fell, scored against 19 news reports (`docs/validation.md`; result so far 0 of 4).
- **Ground and sea:** wet ground and tide / storm surge in both solvers and the risk index.
- **Officer brief** (English / Telugu, print or copy), **sure / maybe** picks, **what money buys** chart, **field reports**.
- **Zone names** from streets, **shareable scenario links**, **1-minute guided demo**, phone layout.
- **Terrain upgrade:** 30 m GLO-30 + OSM drains with a before/after replay check (`make upgrade-check`).
- **Hackathon docs:** `SUBMISSION.md`, `AI_DISCLOSURE.md`, `docs/48-hour-plan.md`, `docs/viva-prep.md`.

### Fixed (November 2026)
- Tide level is measured above its 31-day mean (the source series is offset by about 0.67 m).
- The printed brief no longer starts with a blank page.

### Changed
- **Timeline:** the row of eight number boxes is replaced by one plain sentence about what is happening (English / Telugu).
- **Storm shape:** the rain is now a symmetric triangle that peaks at the midpoint of the duration (previously at 40 %) and falls to zero at the end.
- **Flood recession:** after the rain stops, standing water recedes with a 1 h time constant (assumed; counted as drained volume). Previously, pockets walled in by building footprints held water for ever (about 2.5 ha still flooded three hours after the rain). Peak depths and peak flooded areas during the rain are unchanged in kind (e.g. 200 mm / 4 h / 50 % blocked: peak 24.0 ha at T+2:14).
- Browser and NumPy solvers updated together; tests now require the peak at the midpoint, a symmetric curve, receding water and a closed mass balance (see the test totals below).
- Assistant corpus and methodology updated to describe both changes.

### Fixed
- **Solver:** a pump emptying a cell could spread NaN through the NumPy solver; pumps with `simulate: true` made the API return 500. No-pump results are unchanged.
- **Assistant:** personal-safety questions now get a pointer to official sources instead of a document fragment; stricter abstention (50 % word match) so off-topic questions no longer match on one or two shared words. Python and browser copies kept identical.
- **API:** unknown drain ids in `overrides` are rejected with 422.

### Performance
- The JavaScript bundle is split (app, React, Three.js, MapLibre); the 2D map is lazy-loaded and prefetched when idle. First-load code roughly halves (about 1.6 MB to 0.8 MB).

### Added
- **Tests:** about 70 new tests for the risk engine, routing, dataset helpers and `gis-engine`, plus assistant tests (Python and browser). Totals: 73 Python + 63 web.
- **Docs:** `docs/data-quality.md` (generated by `gis-engine/data_quality.py`) and `docs/validation-plan.md` (a plan, not a result, for testing the model against a real storm).
- **Drains tab:** an indicative ranking of which drains are most likely to block (terrain, built-up surroundings, spacing; assumed weights) and which matter most if they do. Colours the drains on the 3D and 2D maps, flies to a selected drain, and can assume the k likeliest drains block. Not a prediction: no real drain or blockage records exist for the area.
- Deployment: `Dockerfile`, `render.yaml`, single-flight guard (HTTP 429) on the slow `simulate` endpoint, live demo links.
- `docs/prototype-guide.md` and the PDF study guide `docs/PRITHVI-AI-study-guide.pdf`.

## [0.1.0] — 2026-11-22
First public prototype.

### Added
- Real-time 3D digital twin of a central Kakinada pilot area: OSM buildings and roads, shaded flowing flood water, rain, sun shadows, drain inlets and facilities.
- Scenario controls (rainfall, duration, drainage blockage, per-inlet blocking, temporary pumps), timeline playback and live statistics.
- Explainable risk index per 100 m zone, baseline-vs-scenario comparison, exposure overlay, priority ranking and road-route analysis.
- 2D map (MapLibre) with peak flood cells; navigation pad with compass in both views.
- Evidence assistant (extractive BM25 with citations and abstain), English / Telugu UI.
- FastAPI backend (11 routes), NumPy reference flood solver, data pipeline (OSM + Copernicus GLO-90), provenance metadata.
- Tests: risk index, TypeScript↔Python parity, solver mass conservation, RAG, API (30 Python + 4 web).
